# Image Generate

使用 1-10 张参考图执行一个或多个独立图片生成任务。

- 图片按输入顺序共同发送，不会逐张生成。
- `Repeat` 模式使用相同的生成输入提交 1-10 个独立请求。
- `Variants` 模式使用一个显式的 `[placeholder]`，将 STRING list 中的每个完整字符串作为一次替换；替换保留换行并替换所有出现位置。
- 请求按有限并发执行，输出按任务顺序及 Provider 结果顺序排列。
- 单个任务失败不会丢弃其他成功结果；只有没有任何有效图片时节点才失败。
- `expanded_prompt` 是结果级输出，与 `images` 一一对应；一个任务返回多张图片时重复对应 Prompt。
- 生成请求只提交一次，不自动重试；轮询和图片下载可以进行有限重试。
- V1 不使用 seed、不自动保存图片、不生成 Prompt 文件名、不提供 manifest 或恢复功能。
- 可选连接 Image Ratio 的比例输出覆盖模型手动比例；未连接时使用手动值。外部比例当前仅支持 RunningHub，并由模型请求适配器按支持比例进行等价匹配。
- 每张 PNG 不超过 10 MB，总计不超过 50 MB。
- 输出可连接 Preview Image、Save Image 或其他图片节点。
